# Contributing to SEOKit

We welcome community contributions to help improve SEOKit! Here is a guide on how to get started.

## Development Setup

1. Fork and clone the repository.
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Build the workspace:
   ```bash
   pnpm build
   ```
4. Run tests:
   ```bash
   pnpm test
   ```

## Pull Request Guidelines

*   Ensure all new features or rule validations include unit/E2E test files.
*   Verify that typechecks compile cleanly.
*   Submit clear and descriptive commit messages.
