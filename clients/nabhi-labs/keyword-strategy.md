# Nabhi Labs — Intent-Driven Keyword Strategy

## How to use this document

This is a working keyword database in Markdown table form, organized exactly per the 10-step process: one cluster per service pillar, each keyword tagged with **Intent**, **Funnel Stage**, and **Priority**. Only Commercial and Transactional keywords are prioritized for landing pages; Informational keywords are reserved for blog/content-hub pages that feed the commercial pages via internal links.

**Data honesty note:** Search Volume, Keyword Difficulty, and CPC columns are marked `TBD` throughout. I don't have access to Ahrefs, Semrush, or Google Keyword Planner — pulling real numbers for the ~200 keywords below (and the further expansion to 500-1,000) needs to happen in one of those tools before you commit budget to any page. Everything else here — the clustering, intent classification, funnel mapping, and priority calls — is usable as-is and was informed by researching the current (Aug 2026) competitive landscape for each pillar rather than guessed.

**Nabhi Labs itself wasn't findable in search** — no indexed site or public profile came up under that name. That's expected for a newer or pre-launch site, but it also means none of this was reverse-engineered from your existing pages; it's built from the service list you gave me plus what's actually ranking for competitors in each category right now.

## Next steps to reach the 500-1,000 keyword target

1. Run every "High" priority keyword above through Ahrefs/Semrush/GKP to fill Volume/KD/CPC — this alone usually surfaces 3-5x more long-tail variants per seed via the tool's own suggestion feature.
2. Scrape the competitor list in Step 5 for their actual ranking keywords (Ahrefs Site Explorer → Organic Keywords) and cross-reference against pillars above — anything they rank for that isn't in this doc yet is a gap to fill.
3. Manually run Google Autosuggest + "People also ask" for each of the ~40 "High priority" seed rows above — each typically yields 5-15 real long-tail expansions.
4. Once Nabhi Labs has a live site with Search Console data, feed actual query data back into this doc quarterly to catch what's already driving impressions but isn't targeted with a dedicated page yet.
