# Off-Site Mention Monitoring

## Overview

The functional group covering GEO's most counterintuitive, highest-leverage lever: branded mentions correlate **0.664** with AI Overview visibility, vs. **0.218** for backlinks — roughly 3x stronger. Critically, the mention does not need to be linked. Under classic SEO an unlinked mention was worth almost nothing; under GEO it's semantic evidence a generative model uses directly.

## How it works

```
Tier 1 — Third-party editorial (highest value)
  Listicles, comparison posts, reviews on authoritative blogs/review sites
  → digital PR, expert contribution (HARO-successors), review-site
    profiles, original data journalism others cite

Tier 2 — User-generated content
  Reddit, Quora, Stack Overflow, niche forums, Discord/Slack
  → genuine participation, disclosed affiliation, NEVER astroturf
    (detectable, gets banned, generates negative sentiment in the
    exact corpus you're trying to influence)

Tier 3 — Owned properties
  YouTube, podcasts, social, documentation, GitHub — lower trust
  weight, fully under your control (see ../06-video-youtube-presence.md)
```

**Why this makes sense:** a generative model builds a picture of "who's credible in X" from how often and in what context entities co-occur with the topic across its corpus. Links are navigational; mentions are semantic evidence — the model cares about the second.

## Tools & what to check

| Tool | Role |
|---|---|
| Ahrefs Content Explorer / Semrush | Finds **unlinked mentions** — outreach gold |
| Google Alerts | Free, crude, set one up today |
| Brand24 / Mention | ~$49–79+/mo — mention monitoring with sentiment |
| Featured / Qwoted / SourceBottle | HARO successors — feeds Tier 1 directly |

Full detail: `../../../research/06-tools-and-platforms.md` §7; tool reference `../../tools/tools-reference.md` TOOL-06.

## Key metrics / thresholds

- Track **linked vs. unlinked mention count**, trended over time — both count
- The narrative gap (queries where competitors are mentioned and you aren't) is the actionable output — see `../../SEO/groups/06-competitive-analysis.md`
- No numeric target for mention count exists; direction of travel is what matters
