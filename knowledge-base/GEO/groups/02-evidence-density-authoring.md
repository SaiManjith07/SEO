# Evidence Density Authoring

## Overview

The functional group implementing the single most evidence-backed finding in this entire knowledge base: the Princeton GEO paper (the only peer-reviewed source in the field). Three content strategies produced measured visibility lift; keyword stuffing produced none.

## How it works

```
For every qualitative claim in a draft:
        │
        ▼
Replace with a STATISTIC — "many users" becomes "62% of users"    (+25.9%)
        │
        ▼
Add a QUOTATION from a named, credible source — not anonymous       (+27.8%)
        │
        ▼
Add an inline CITATION to a primary source                          (+24.9%)
        │
        ▼
Combined: up to 40% visibility lift, position-adjusted word count
```

**The pattern behind the results:** all three strategies do the same thing — they make claims *verifiable*. A generative model synthesising an answer needs content it can safely reproduce and attribute. A statistic with a source is safe to quote; a vague assertion is not.

**Honest caveat:** if everyone adds statistics and quotes, the relative advantage compresses — these are becoming table stakes, not an edge. Still worth doing; just don't expect the same lift forever.

## Standards it touches

STD-23 (Evidence density — the Princeton trio) — `../../standards/06-aeo-geo-content.md`. This is the only standard in the whole knowledge base backed by peer-reviewed research (arXiv:2311.09735, KDD 2024).

## Tools & what to check

No commercial tool scores this directly. Manual editorial review: count numeric claims, quoted/attributed statements, and outbound citations per section. Original data (proprietary surveys, benchmarks) is the most reliable way to generate genuinely new statistics rather than recycling others'.

## Key metrics / thresholds

- Quotation Addition: **+27.8%** visibility lift
- Statistics Addition: **+25.9%**
- Cite Sources: **+24.9%**
- Combined top-three: **30–40% relative improvement**
- Keyword stuffing: **no meaningful improvement**, sometimes negative
