# Quick Start Guide

SEOKit analyzes and optimizes website page properties for AI search bot accessibility.

## 1. Global Setup

Install the command client:
```bash
npm install -g seokit
```

## 2. Initialize Integrations

To setup Cursor or Claude Desktop automatically:
```bash
seokit init
```

## 3. Run a Scan

To audit the local directory:
```bash
seokit verify
```
This generates JSON and Markdown files inside `.seokit/reports`.
