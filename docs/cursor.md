# Cursor MCP Integration

SEOKit registers as a Cursor Model Context Protocol server.

## Installation

1. Run initialization:
   ```bash
   seokit init
   ```
2. This creates `.cursor/mcp.json` automatically inside the workspace root.
3. Open Cursor settings -> MCP, and ensure `seokit` is listed.
4. Restart the Cursor app or reload window to discover the new tools.
