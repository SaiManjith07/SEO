# Antigravity MCP Integration

SEOKit integrates as a workspace agent skill or workspace MCP server in Antigravity.

## Auto-Registration

Running `seokit init` generates the workspace config at:
```text
.agents/mcp.json
```
Antigravity automatically discovers and connects to the SEOKit MCP server using this file.
Once connected, the agent will have active access to the SEO verification, AI content generation, and automated remediation tools.
